# Movie Recommender 

A Python project that recommends movies based on the user's preferred genre.

## Features
- Choose from five movie genres.
- Get three movie recommendations.
- Search for another genre.
- Exit the program when finished.

## Technologies
- Python

## Python Concepts Used
- Dictionaries and lists
- While loops and for loops
- If, elif and else statements
- User input
- Break and continue
- String methods: lower() and strip()

## How to Run

Run the Python file using the following command:
python3 movie_recommender.py
